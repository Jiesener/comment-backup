# 评论取用站

共享云端评论池。**所有设备共读共写同一份 `data.json`**，复制即从池中永久取走该条，
其他设备不会再看到它（等价 NAS 主站的「复制即原子删除」）。

- 访问：`?u=<账号>`（`ycy` / `hxy` / `share` / `yanghao`）
- 数据：`data.json`，由 NAS 评论池导出，**不含任何凭据**
- 运行时配置：`config.js`（仓库 token + 仓库坐标），**必须和 index.html 一起部署**

并发安全：写入走 GitHub Contents API 的 SHA 乐观锁；冲突时重拉最新、
若该条已被别人取走则提示并自动换条。
